# Talent One

Next.js app using the App Router, TypeScript, Tailwind CSS, and ESLint.

## Getting started

Install dependencies and start the development server:

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The home page is
`src/app/page.tsx`; shared layout and styles live in `src/app/layout.tsx` and
`src/app/globals.css`.

## Scripts

- `npm run dev` - start the development server
- `npm run lint` - run ESLint
- `npm run build` - create a production build
- `npm run start` - serve the production build
